About Me

I'm a motivated and curious learner from Bhutan, currently pursuing a Diploma in Computer System and Network at Jigme Namgyel Engineering College (2025 – Present). I enjoy taking a problem apart, understanding how each piece works and then putting together a clear solution, whether that's a routing configuration, a Linux server or a web page.

Full-Stack Web App · Team Project In progress

AutoConnection — Auto Workshop Management System

A web system that replaces a workshop's paper job cards with one database and a separate dashboard for each role. Customers book and track repairs online, mechanics manage their assigned jobs, and admins oversee stock, suppliers, staff and reports. A three-person team project at JNEC, built in Agile sprints.

  • Customer — register, add vehicles, book a repair with photos, track its live status and buy spare parts.
  • Mechanic — see assigned repair orders, move them from Pending to In progress to Complete, and log parts used.
  • Admin — assign mechanics, manage inventory and suppliers, approve purchase orders and generate reports.
  • Security — passwords hashed with bcrypt, JWT login and role checks on every request.

IoT · Embedded Systems

Smart Room Automation with Arduino

A mini project of three Arduino Uno systems that show how sensors, actuators and a microcontroller work together to automate a room, with energy-saving and touch-free designs for homes and public spaces.

  • Smart Room Lighting — a PIR motion sensor detects a person and the Arduino switches an AC bulb through a relay module.
  • Smart Dustbin — an HC-SR04 ultrasonic sensor detects a hand and a servo motor opens the lid.
  • Automatic Door — the ultrasonic sensor detects a person approaching and a servo opens and closes the door.
  • Arduino Uno
  • Arduino IDE (C++)
  • PIR Sensor
  • HC-SR04
  • Servo Motor
  • Relay Module
